# OpenGame AI Game Generator — Privacy

Effective date: September 6, 2026. Publisher: OpenGame.

This notice covers the free Skills-only OpenGame AI Game Generator package
distributed from this repository. It runs with the file and Python tools of
your host assistant, such as ChatGPT or Codex.

## Prompts and project files

The packaged helper does not make network requests or send prompts, game
files, workspace contents, account information, or telemetry to OpenGame.
It creates and revises files in the workspace you select. The package has no
OpenGame sign-in, account connection, or cloud-storage integration.

Your host assistant processes your conversation and files under its own
privacy policy, data controls, and retention settings. This package does not
change those controls. Use your host's controls to manage conversations and
stored files; local project files can be removed from your selected workspace.

## Optional website links and support

The starter game and documentation contain optional OpenGame website and
showcase links. The game does not open these links automatically. Some links
include fixed campaign parameters identifying the OpenGame Skill; they do
not include your prompt, account identifier, or project contents. The starter
footer can be removed without affecting the game.

If you visit the website or contact support, the information you choose to
provide is handled under the [OpenGame website privacy policy](https://opengame.app/privacy-policy).
GitHub handles visits to this repository under its own privacy policy. Host
assistant services and GitHub are separate service providers.

Changes that you or your assistant make to a generated game's code can add
different behavior, including network access. Review that code before sharing
the game; this notice describes the distributed package's behavior.

## Contact and updates

Contact [support@opengame.app](mailto:support@opengame.app) with questions about
this package. Share only the information needed for support, and do not send
passwords or API keys. Material changes to this notice will be recorded here
with an updated effective date and in the relevant package release notes.
