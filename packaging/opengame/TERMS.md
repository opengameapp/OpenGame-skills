Effective date: September 6, 2026. Publisher: OpenGame.

## Free package and host requirements

OpenGame AI Game Generator is a Skills-only package for creating, revising,
and exporting small offline 2D browser-game prototypes. It includes a
collect-and-dodge starter, original SVG artwork, a Python helper, and workflow
instructions. Your host must provide access to the package files, a writable
workspace, and Python 3. Gameplay testing also requires browser tools.

Using the package does not require an OpenGame account, a payment to OpenGame,
or OpenGame credits. Access to your host assistant and its tools is governed
by that provider's separate terms, subscriptions, and usage limits. Website
accounts, hosted generation, cloud saves, multiplayer, and Blender integration
are not included in this version.
