# OpenGame social video matrix

Use the operator's exact selected destinations. This matrix is a presentation
default, not standing publication authority.

| Destination | Default OpenGame delivery | Important boundary |
| --- | --- | --- |
| YouTube | Native reviewed landscape video; publish a reviewed vertical Short as a separate operation when requested | The landscape upload and Short need distinct identities and URLs. |
| X | Native landscape video with the canonical playable URL in the post copy | A YouTube-link post is not a substitute for a requested native video. |
| Bluesky | Native landscape video with the canonical playable URL | Verify the public record exposes a video embed. |
| TikTok | Native vertical video, publish-now or exact local schedule | A scheduled item is not yet a public post. |
| Instagram | Native vertical Reel by default | A reviewed landscape render may be used only when explicitly selected and the current account/platform validation accepts it. |
| Facebook | Native vertical Reel by default | A reviewed landscape render may be used only when explicitly selected and the current account/platform validation accepts it. |
| Discord | Link-only message containing the reconciled public YouTube URL | Do not upload a redundant native attachment unless explicitly requested for that exact message. |
| Reddit | Native hosted video plus concise body and canonical URL when the community permits it | Confirm `is_video`, hosted-video metadata, and a working public player. |

Exclude Telegram or another destination when the operator excludes it or when
no owned account/channel configuration exists.

Keep the canonical OpenGame page URL in native social copy when direct traffic
is the goal. A link in a later reply is an optional, separately executed tactic,
not a replacement for the main post's CTA.
